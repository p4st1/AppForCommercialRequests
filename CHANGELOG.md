# Changelog

Все значимые изменения проекта фиксируются в этом файле.

## [Unreleased] - 2026-05-06

### Added
- Импорт Excel для таблиц retrade с учетом формульных ячеек и денежных значений.
- Дополнительные проверки сценариев импорта, экспорта и пересчета retrade.

### Changed
- Улучшено заполнение Excel-экспортов retrade и обработка колонок рейтинга.
- Обновлены локальные служебные данные авторизации и профиль Playwright после проверки интеграции с торговой площадкой.

### Fixed
- Добавлены свежие диагностические записи по ошибкам расчетных колонок и `401 Unauthorized` для дальнейшего разбора авторизации.
- Проверено подключение к `etp.metal-it.ru` с Windows user-agent: сайт и страница подачи заявки отвечают `HTTP 200`; текущая ошибка подачи связана с `401 Unauthorized` из-за невалидных cookies/авторизации, а не с ограничением macOS.

## [3.0.1] - 2026-05-04

### Fixed
- Исправлены зависимости и проверки в release workflow.
- Уточнены проверки авторизации и безопасной отправки предложений на платформу.
- Исправлены тестовые сценарии для потоков расчета, DOCX из Excel и загрузки предложений.

### Tests
- Добавлено покрытие для парсинга расчетов retrade и граничных случаев экспорта.

## [3.0.0] - 2026-05-04

### Added
- Интеграция с торговой площадкой: авторизация, проверка статуса входа, GraphQL-загрузка торгов и сохранение cookies/XSRF.
- Поиск торгов по номеру, фильтрация активных заявок и ограничение количества загружаемых торгов.
- Web-процесс для КП: загрузка торгов, поиск подходящего лота, экспорт и постобработка Excel.
- Рабочий процесс retrade с отдельным окном, вкладками заявок и расчетов, загрузкой ставок и экспортом через Playwright.
- Импорт и генерация Excel для retrade, включая формулы, валюты, пересчитанные значения, рейтинг и исправленный рейтинг.
- Настройки автоторгов и таймера автоматической проверки.
- Диагностические HTML/PNG-снимки для разбора ошибок браузерного экспорта.

### Changed
- Главное окно и retrade UI перенесены в Qt Designer.
- Логика интерфейса разделена на mixin-модули, добавлены отдельные сервисы авторизации, платформы, экспорта и расчетов.
- Таблицы retrade получили Excel-подобный вид, автоподбор ширины колонок, настройки внешнего вида и форматирование валют.
- Добавлены платформенные темы для macOS и Windows.

### Fixed
- Повышена стабильность экспорта повторных торгов через Playwright и обработку сетевых ответов.
- Исправлен разбор ставок из `/trades`, обработка экспортируемых файлов и формулы исправленного рейтинга.

### Tests
- Добавлены тесты для сервисов платформы, авторизации, экспорта, расчетов, импорта Excel, истории, конфигов и UI-потоков.

## [2.0.0] - 2026-02-27

### Added
- Вкладка `История` с просмотром созданных документов и экспортов.
- Повторное создание КП из истории для DOCX.
- Фильтрация таблиц по значениям, подстроке и пустым полям.
- Гибкий редактируемый блок формул с проверкой выражений.
- Улучшенный импорт CSV/Excel с автопоиском заголовков и устойчивостью к ошибочным строкам.
- Поиск по заказчикам и быстрый массовый выбор при создании КП.

### Changed
- Полностью обновлён интерфейс приложения и визуальная иерархия элементов.
- Переработаны расчёты логистики, валют и итоговых значений.
- Улучшен экспорт DOCX/XLSX и запись данных о генерации в историю.
- Улучшена миграция и структура базы данных для сохранения истории действий.
- Синхронизация служебных файлов (`config`, шаблоны, БД) сделана устойчивее при обновлениях.

### Fixed
- Исправлены ошибки редактирования таблицы и обновления итогов.
- Исправлены сбои при экспорте и обработке некорректных входных данных.
- Добавлены дополнительные проверки настроек и автосоздание директорий сохранения.
